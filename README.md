# Telegram bot + website

Этот проект запускает сайт опроса и отправляет в Telegram номер телефона и IP посетителя.

## Что сделано

- сайт показывает опрос;
- после опроса открывается страница ввода телефона;
- после отправки телефона показывается экран загрузки;
- бот присылает сообщение вида `номер: ...` и `IP: ...`;
- у новой заявки есть кнопка `Взять лог`;
- после нажатия у IP появляется ник пользователя и кнопки меняются на `Принять` и `Отклонить`;
- после нажатия `Принять` сайт открывает страницу ввода имени;
- имя отправляется в Telegram в той же заявке;
- после отправки имени сайт снова показывает экран загрузки.

## Запуск

1. Установите зависимости:

```bash
npm install
```

2. Создайте `.env` на основе `.env.example`.

3. Укажите:

- `TELEGRAM_BOT_TOKEN` - токен от `@BotFather`;
- `TELEGRAM_CHAT_ID` - ваш chat id.

4. Запустите сервер:

```bash
npm start
```

5. Откройте сайт:

```text
http://localhost:3000
```

## Как получить chat id

1. Создайте бота через `@BotFather`.
2. Запустите проект.
3. Напишите боту команду `/start` или `/id`.
4. Бот пришлет ваш `chat_id`.
5. Вставьте его в `.env` и перезапустите сервер.
